# WebGL Lighting System

## Overview
This project implements a lighting system in WebGL using Phong shading with point light attenuation. The system allows objects to be illuminated dynamically based on their distance from a light source.

## Features
- **Phong Shading**: Implements ambient, diffuse, and specular lighting components.
- **Point Light Attenuation**: Light intensity decreases with distance from the source.
- **Material Rendering**: Enhances visual depth and material realism.
